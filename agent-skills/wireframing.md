# Wireframing Skill

## Objective
Produce task-focused, structurally correct wireframes before visual polish.

## Procedure
1. Identify primary user task and success outcome.
2. Establish information hierarchy.
3. Choose an appropriate page structure.
4. Reuse known product patterns.
5. Represent loading, empty and error states when relevant.
6. Keep visual styling intentionally lightweight.
7. Validate navigation, hierarchy and interaction affordances.

## Output
Wireframes should remain editable and should not introduce a visual design system that has not been discovered.
