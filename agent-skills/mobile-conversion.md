# Mobile Conversion Skill

## Objective
Convert an existing desktop experience into a mobile experience without blindly shrinking the desktop layout.

## Procedure
1. Inspect the desktop hierarchy and content dependencies.
2. Inspect an existing mobile screen from the same project when available.
3. Infer reusable mobile patterns from evidence.
4. Rank content by user task priority.
5. Convert columns, sidebars and dense controls deliberately.
6. Preserve real components and variables.
7. Use the project's mobile spacing, type and breakpoint conventions.
8. Screenshot and review the resulting composition.
9. Repair only evidence-backed issues.

## Forbidden
- Arbitrary new breakpoints without project evidence.
- Recreating existing components as primitives.
- Hiding important content solely to make the screen fit.
