# Responsive Design Skill

## Desktop to mobile
1. Identify semantic sections.
2. Rank content by task priority.
3. Identify fixed, fluid and intrinsic dimensions.
4. Collapse multi-column structures when evidence supports stacking.
5. Preserve components when mobile variants exist.
6. Adapt navigation, filters, tables and dense media deliberately.
7. Validate the mobile viewport structurally and visually.

## Defaults
Use project tokens and existing breakpoints first. Never introduce a new breakpoint solely because it is familiar from another product.
