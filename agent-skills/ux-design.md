# Senior UX Design Skill

## Objective
Make the resulting interface understandable, task-oriented and consistent with the product context.

## Review order
1. User goal and primary task
2. Information hierarchy
3. Content prioritization
4. Interaction clarity
5. Error prevention
6. Accessibility
7. Visual consistency

## Rules
- Do not optimize for visual novelty at the cost of comprehension.
- Preserve established patterns when they serve the same task.
- Make assumptions explicit when evidence is incomplete.
- For mobile, prioritize one clear primary action and reduce competing density.
