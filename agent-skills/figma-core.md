# Figma Core Skill

## Purpose
Operate on real, editable Figma nodes using evidence from the current file.

## Workflow
1. Inspect current selection, nearby hierarchy, components, variables and styles.
2. Prefer existing project assets over recreated primitives.
3. Plan bounded, reversible actions.
4. Execute through structured actions.
5. Re-inspect the result before declaring success.
6. Use screenshots for visual verification when available.

## Rules
- Never invent node, component or variable IDs.
- Preserve unaffected content.
- Prefer minimal diffs for edits.
- Do not detach instances unless explicitly required.
