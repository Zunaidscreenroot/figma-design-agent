# Agent Evaluation

Use repeatable tasks to compare agent versions.

Each task should specify:
- user goal
- starting Figma context
- expected design-system reuse
- expected structural behavior
- expected responsive behavior

Recommended score dimensions:
- action validity
- component reuse
- token reuse
- structural correctness
- visual similarity
- UX correctness
- unnecessary mutation count
- repair count

The goal is not a user-facing score. It is an engineering regression suite.
